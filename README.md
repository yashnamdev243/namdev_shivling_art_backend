# Node.js Express MySQL Starter

## Features
- Express
- MySQL (mysql2 + Sequelize)
- phpMyAdmin compatible
- JWT
- bcrypt
- Multer
- Express Validator
- Helmet
- CORS
- Compression
- Morgan
- Rate Limiting
- Nodemailer
- Axios
- Cookie Parser
- dotenv

## Setup

```bash
npm install
copy .env.example .env
```

Update DB credentials.

Run:

```bash
npm run dev
```

Create database in phpMyAdmin matching DB_NAME.
